0.2.2 2026.10.07 LATEST

Pin any file, pick properties from a list, and make pirep your Markdown app.어떤 파일이든 핀하고, 속성을 목록에서 고르고, pirep을 마크다운 기본 앱으로 정할 수 있어요.

ADDED
+ Pin button in the title bar, next to Edit, and ⌘D. Works for every file pirep opens — Markdown, HTML, PDF, CSV and more — and they all gather under Pinned. A Markdown file's pin is still its pinned property.제목 표시줄에서 Edit 옆 핀 버튼이나 ⌘D로 파일을 핀할 수 있어요. pirep이 여는 Markdown, HTML, PDF, CSV 등 모든 파일이 Pinned에 모여요. Markdown 파일의 핀은 기존 pinned 속성으로 저장돼요.
+ Add property now lists pirep's own fields (pinned, status, tags, created, updated) and the properties already used in your Base. Type to search, or create a new one.속성 추가 목록에서 pirep 전용 속성(pinned, status, tags, created, updated)과 Base에서 이미 쓰는 속성을 볼 수 있어요. 검색하거나 새 속성을 만들 수 있어요.
+ Settings › Base › Opening files shows which app opens Markdown files and can make pirep the default.Settings › Base › Opening files에서 Markdown 파일을 여는 앱을 확인하고, pirep을 기본 앱으로 정할 수 있어요.
0.2.1 2026.10.06

Window fixes for files opened from outside a Base.Base 밖 파일 창과 창 닫기 동작을 고쳤어요.

FIXED
· Windows for files outside a Base can be dragged by the title bar again; they showed a “start_dragging not allowed” error.Base 밖 파일 창을 제목 표시줄로 다시 끌 수 있어요. 전에는 “start_dragging not allowed” 오류가 떴어요.
· ⌘W closes only the front window. ⌘Q still quits pirep.⌘W는 맨 앞 창만 닫아요. ⌘Q는 그대로 pirep을 종료해요.
· Closing the main window keeps pirep in the Dock; click the Dock icon to bring it back.메인 창을 닫아도 pirep은 Dock에 남아요. Dock 아이콘을 누르면 다시 열려요.
0.2.0 2026.10.06

Markdown files open from Finder, and Quick Look shows them rendered.Finder에서 마크다운 파일을 열 수 있고, Quick Look으로 렌더링된 모습을 볼 수 있어요.

ADDED
+ Quick Look: press Space on a Markdown file in Finder for a rendered preview. Text appears first; code colour, maths and Mermaid diagrams follow.Quick Look — Finder에서 마크다운 파일을 고르고 Space를 누르면 렌더링된 미리보기가 떠요. 글이 먼저 나오고 코드 색·수식·Mermaid 다이어그램이 뒤따라요.
+ Open Markdown files from Finder. A file inside a Base opens in the main window with the file selected in Files.Finder에서 마크다운 파일을 pirep으로 열 수 있어요. Base 안의 파일은 메인 창에서 열리고, Files에서 그 파일이 선택돼요.
+ A file outside every Base opens in its own window, where you can read and edit it; nothing is written to that folder unless you choose Add this folder as a Base.어느 Base에도 없는 파일은 따로 창에서 열려 읽고 고칠 수 있어요. Add this folder as a Base를 고르기 전에는 그 폴더에 아무것도 쓰지 않아요.
+ To have the Open with button in Quick Look show pirep, select a Markdown file, press ⌘I, choose pirep under Open with, and press Change All.Quick Look의 Open with 버튼에 pirep이 뜨게 하려면 마크다운 파일을 고르고 ⌘I를 눌러 Open with에서 pirep을 고른 뒤 Change All을 누르세요.
0.1.4 2026.10.02

HTML slides present full screen again, and HTML previews can move through pages.HTML 슬라이드가 다시 전체 화면으로 열리고, HTML 미리보기에서 페이지를 오갈 수 있어요.

ADDED
+ HTML previews get Back and Original buttons and ⌘[ / ⌘] to move through pages.HTML 미리보기에 Back·Original 버튼이 생기고, ⌘[ / ⌘]로 페이지를 오갈 수 있어요.
+ Mark all read for the Updates and Unread sections of the queue.읽을 목록의 Updates·Unread 구역에 모두 읽음 처리가 생겼어요.
CHANGED
· External https links open in your default browser.외부 https 링크는 기본 브라우저에서 열려요.
FIXED
· HTML slides present full screen again, with the preview still isolated.HTML 슬라이드가 다시 전체 화면으로 열려요. 미리보기는 계속 앱과 분리돼 있어요.
0.1.3 2026.09.30

HTML previews now work the way they do in a browser, and links can be autocompleted.HTML 미리보기가 브라우저에서처럼 동작하고, 링크를 자동완성할 수 있어요.

ADDED
+ Link autocomplete — type [[ for documents or ]( for other files.링크 자동완성 — [[ 를 치면 문서, ]( 를 치면 그 밖의 파일 목록이 떠요.
CHANGED
· HTML previews load from their own origin with their own rules, so a document’s stylesheets, fonts and scripts work as they do in a browser.HTML 미리보기를 앱과 분리했어요. 문서의 스타일시트·글꼴·스크립트가 브라우저에서처럼 동작해요.
· The preview cannot reach the app’s commands.미리보기 속 문서는 앱 기능에 접근할 수 없어요.
· App shortcuts still work while focus is inside an HTML preview.HTML 미리보기 안에서도 앱 단축키가 동작해요.
0.1.2 2026.09.21

Opens on the light theme unless you have chosen otherwise.따로 고르지 않았다면 라이트 테마로 열려요.

0.1.1 2026.09.18

Checks for a new release at startup and offers it in a banner — nothing downloads until you ask.켤 때 새 버전이 있는지 확인하고 띠로 알려요. 누르기 전에는 아무것도 받지 않아요.

ADDED
+ Update check at startup, offered in a banner. Nothing downloads until you ask.켤 때 업데이트 확인, 띠로 알림. 누르기 전에는 받지 않아요.
FIXED
· The macOS bundle is now properly sealed, so a downloaded copy no longer reports itself as damaged.macOS 앱 묶음을 제대로 서명해서, 내려받은 앱이 더 이상 ‘손상됨’으로 뜨지 않아요.
0.1.0 2026.09.18

First pirep release.pirep 의 첫 릴리스예요.

ADDED
+ Knowledge Inbox — changed notes and notes you have not read yet, on one screen.Knowledge Inbox — 바뀐 문서와 아직 안 읽은 문서를 한 화면에 모아요.
+ Review changes (⌘U) — accept or dismiss updates across several notes in one pass.바뀐 내용 모아 보기(⌘U) — 여러 문서의 업데이트를 한꺼번에 반영하거나 되돌려요.
+ File type chips — markdown, files the app can display, and files it cannot open are told apart by colour.파일 종류 칩 — 마크다운, 앱이 보여 줄 수 있는 파일, 열 수 없는 파일을 색으로 구분해요.
+ HTML · PDF · CSV · image viewers — non-markdown files open inside the app.HTML · PDF · CSV · 이미지 보기 — 마크다운이 아닌 파일도 앱 안에서 열려요.
+ Tag results and Rabbit Hole — gather notes by tag, and keep the trail of what you read next.태그 결과와 Rabbit Hole — 태그로 문서를 모으고, 이어 읽은 흐름을 남겨요.
+ Eight settings tabs.설정 탭 여덟 개.
+ The sidebar can be resized by dragging its edge.사이드바 가장자리를 끌어 폭을 바꿀 수 있어요.
+ The note path sits in the centre of the title bar.문서 경로가 제목줄 가운데에 있어요.
+ Search at the top of the sidebar.검색이 사이드바 맨 위에 있어요.
+ ⌘R opens Related Topics; ⌘⇧R marks a note as read.⌘R 로 관련 문서, ⌘⇧R 로 읽음 표시.
+ Edits that arrive in bursts are recorded once, after 0.4s of quiet.몰려서 들어오는 저장은 0.4초 조용해진 뒤 한 번만 기록해요.
