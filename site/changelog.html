0.1.1 2026.09.18 LATEST

The reading queue and the changes view were rebuilt. Files are now sorted into three tiers by what pirep can do with them, and the whole interface was reset around the light theme.읽을 것 목록과 바뀐 내용을 보는 화면을 새로 짰어요. 파일 종류를 세 단계로 구분하고, 화면 전체를 라이트 테마 기준으로 다시 맞췄어요.

ADDED
+ Knowledge Inbox — today’s date alongside changed notes and notes you have not read yet, on one screen.Knowledge Inbox — 오늘 날짜와 함께 바뀐 문서, 아직 안 읽은 문서를 한 화면에 모아요.
+ Review changes (⌘U) — accept or dismiss updates across several notes in one pass.바뀐 내용 모아 보기(⌘U) — 여러 문서의 업데이트를 한꺼번에 반영하거나 되돌려요.
+ File type chips — markdown, files the app can display, and files it cannot open are told apart by colour.파일 종류 칩 — 마크다운, 앱에서 볼 수 있는 파일, 열 수 없는 파일을 색으로 구분해요.
+ HTML · PDF · CSV · image viewers — non-markdown files now open inside the app.HTML · PDF · CSV · 이미지 뷰어 — 마크다운이 아닌 파일도 앱 안에서 열려요.
+ Tag results and Rabbit Hole — gather notes by tag, and keep the trail of what you read next.태그 목록과 Rabbit Hole — 태그로 문서를 모아 보고, 이어 읽은 길을 남겨요.
+ Eight settings tabs — Editor, Version history, Templates and Account are now separate.설정 탭 여덟 개 — 편집기, 버전 기록, 템플릿, 계정을 각각 나눴어요.
CHANGED
· Light is now the default theme. Dark is chosen in Settings › Appearance.라이트 테마가 기본이 됐어요. 다크는 설정 → Appearance에서 골라요.
· The sidebar can be resized by dragging its edge.사이드바 폭을 끌어서 조절할 수 있어요.
· The note path moved to the centre of the title bar. Clicking a folder name jumps to that folder.문서 경로를 창 위쪽 가운데로 옮겼어요. 폴더 이름을 누르면 그 폴더로 넘어가요.
· Search moved to the top of the sidebar.검색을 사이드바 맨 위로 옮겼어요.
· ⌘R still opens Related Topics. Mark as read is now ⌘⇧R and mark all read is ⌘⌥R.⌘R은 Related Topics 그대로예요. 읽음으로 표시는 ⌘⇧R, 모두 읽음은 ⌘⌥R로 바뀌었어요.
· The interface is English only for now. Korean is on the way.화면 언어는 지금 영어만 있어요. 한국어는 준비 중이에요.
FIXED
· Some edits were missed when saves arrived in bursts. pirep now waits 0.4s and records once.파일이 몰려 저장될 때 일부 변경을 놓치던 문제를 고쳤어요. 0.4초 기다렸다가 한 번만 기록해요.
